= Columnar values and retained pages

Columnar builders and readers are passive call-owned transforms.
`OwnedBatch`, `OwnedColumn`, and cloned Arrow arrays retain their allocation reservations independently of the query cursor.
`MemoryBudget` and `MemoryReservation` re-export the shared byte-admission types from `rtdb-types`.
Schema codecs preserve native logical types and the full signed decimal precision and scale at external boundaries.

Execution admission uses `execution_type`, `execution_field_type`, `admit_execution_value`, and `read_execution_value`.
Unsigned integer storage is read as the signed integer of the same width, including nested cells, matching the pinned Arrow vector opener.
The in-place value adapter preserves integer bits and existing allocations.
The type adapter retains nullability and child encodings and joins union legs that become equal.
Raw `from_field` and `read_value` preserve physical types and values for IPC, source payloads, durable artifacts, and inspection.
Callers apply admission to domain values entering execution; spill sequence numbers and group identities retain their unsigned representation.
Calendar objects entering `admit_execution_value` or `build_array` use the reference vector object writer's day truncation and millisecond multiplication rules.
`copy_array` and semantic vector hashes reject unadmitted calendar objects, including nested cells.
Expression evaluation applies its checked day narrowing before handing completed values to these stored-cell surfaces.

`DeclaredBatch` retains a wire schema and a page conformed to that schema's physical layout.
`conform_batch` reserves schema work, decoded values, and builders before allocating them.
It preserves integer bits and exact decimal metadata, fills nullable missing fields, and rejects fields outside the target layout.
Adaptation preserves declared nested field order, child names, metadata and dense union type IDs.
Set and timestamp-range extensions retain their declared child layouts while validating the extension's storage container.
Signed execution integers conform to a same-width unsigned declared field by retaining their buffer bits under the declared physical type.
Named union admission still requires a matching declared leg.
Single typed columns are wrapped in declared unions, and nullable rows select the union's NULL leg.
Exact-schema pages pass through with their original physical layout.
Present NULL values can promote physical field nullability while the declared wire flags stay unchanged, following `core/src/main/kotlin/xtdb/arrow/ConformingUnloader.kt`.
The internal RecordBatch uses checked constructors; Flight IPC and C exports supply the separate declared schema.
This adapter's source tests cover null promotion, nested layouts, union remapping, column order, retained memory, missing required columns and decimal metadata mismatch.
All compilation, execution, and cross-runtime qualification remain pending.

URI object writes and reads validate Java URI syntax while retaining the original UTF-8 spelling and extension layout.
`tests/uri.rs` covers invalid stored spellings and object inputs as unexecuted regression source.

== Physical execution cells

`ExecutionVector` opens a retained `OwnedColumn` and an Arrow field under the column's memory budget.
`with_reservation` also accepts a pre-reserved raw Arrow allocation without first applying `OwnedBatch`'s nested nullability validation.
It checks buffer coverage and retains the original array and reservation privately until the final dependent view drops.
Opening validates the admitted layout before publication and ignores validity buffers on declared nonnullable nodes, matching the pinned vector loaders.
The original Arrow arrays remain unchanged and every payload buffer stays shared.
The opened schema is bounded to 128 levels and each vector length to the signed 32-bit index domain.
HALF vectors are rejected by this execution opener.
Timestamp timezone names are validated when opening, including empty and nested vectors.
`descriptor()` borrows the canonical `VectorDescriptor`: unsigned integer widths become signed, timestamp zones use `ZoneId` spelling, and union/run-end parents have no validity field.
Scalar descriptors retain one validated scalar `Field`; container descriptors retain their native kind and ordered children.
`ingress_field()` returns `DeclarationRef::Arrow` for an original admitted declaration and `DeclarationRef::Native` when only a native descriptor exists.
`arrow_field()` allocates checked SDK metadata in a `RetainedArrowField`; every clone retains the projection's reservation.
Native union descriptors retain all ordered children and wrapping ordinal discriminators independently of SDK schema limits.
Native union construction reserves logical-join scratch for cloned ancestor maps across the bounded descriptor depth before retaining children; their existing metadata leases remain independent.
SDK projection rejects a native union with more than 128 children without removing its children or changing its native descriptor.
The native descriptor and its SDK projection preserve custom child/leg names and declaration order.
`logical_type()` borrows cached execution metadata or returns an allocation-free `VectorTypeFailure`.
Native run-end types over Null or Nothing retain the exact source Unsupported outcome, including its width; enclosing types propagate the first child failure in source order.
The typed outcome has no implicit `Anomaly` conversion, because its source Unsupported error has no error-code key.
Scalar descriptors retain a guaranteed logical type beside their validated Field.
`CellRef::leaf_descriptor()` preserves the actual selected union leaf even when that leaf is null.
Physical Field nullability, concrete reader nullability and logical type admission are independent: run-end fields are nonnullable, while `reader_nullable()` delegates to their values.
Field projection and concrete getters do not request logical type metadata.
Structural logical Value reads use concrete descriptor kinds, so a nested type failure does not introduce an unrelated read failure.
Native nested run-end metadata replaces the outer encoding and retains child encodings; timestamp-range logical metadata uses its fixed timestamp element type while its Field retains the actual child.
Native signed fixed-list widths remain representable as metadata and SDK Fields, while strict external schema and array admission continue rejecting negative widths.

`from_physical` admits immutable Struct, List/Map, FixedSizeList, DenseUnion and RunEndEncoded containers without requiring a parent Arrow array.
Scalar children retain either admitted Arrow or immutable native scalar storage.
Public scalar ingress continues to use the validated Arrow opener.
Each `RetainedBuffer` owns its buffer allocation reservation; child vectors retain their own owners, and native metadata is reserved before cloning or publishing it.
Container admission checks declarations, complete direct children, row counts, validity spans and child offsets.
Native and Arrow run-end admission checks every retained end, including unused runs behind sliced, empty and nested readers.
Run ends must be positive, strictly increasing and within `i32::MAX`, with one value per run and final coverage at least the logical length.
A shorter logical length, including zero, retains the complete covering run table and its value owners.
Arrow admission also preserves the SDK's offset-plus-length coverage validation.
Dense unions retain every negative discriminator byte as an absent leg.
Named-leg selections retain raw signed offsets without checking the final child's bounds; nested selection checks only intermediate offset/index entries it actually reads.
Consuming getters check retained payload bounds before access.
Internal receiver positions stay signed through forwarding and method dispatch.
Unsupported methods reject their receiver class before checking a final leaf position.
Null-vector nullness is constant true, and nonnullable scalar/container nullness is constant false; neither operation reads row storage.
Nullable validity, union discriminators/offsets, indirect indices, run ends and actual payload reads retain their own checked accesses.
An absent leg is null for `is_null`, has no `leg_name`, and fails primitive/object reads; it remains distinct from an explicit Null leg and from a null nullable Duration leaf.
No invalid Arrow union is constructed.

Forwarding primitive getters, `get_bytes` and concrete numeric wrappers return `VectorReadResult`.
`VectorReadError::AbsentPrimitiveReceiver` retains the raw message-less NullPointerException producer separately from `VectorReadError::Anomaly`.
Absent primitive receivers propagate through union, run-end, named-leg and indirect readers.
At each absent DenseUnion receiver, failure precedes reading that union's offset or admitting a leaf getter.
Object reads retain their distinct `no leg for index` diagnostic.
No implicit conversion chooses an anomaly message for a raw absent receiver.
Production adapters must still select the actual host conversion route: Kotlin's `toAnomaly` supplies its Fault default, while Clojure's primary constructor preserves a nil message.
The nullable anomaly carrier is shared; the physical producer-to-host adapters remain outside this reader increment.

Direct ranges and composed selections preserve source row indices without taking Arrow payload copies.
`CellRef` borrows a selected position; `OwnedCell` retains its buffer, metadata and normalized index owners.
Primitive getters resolve dense-union offsets and run-end physical indices before method admission and validity checks.
`NullChecks` is an explicit read parameter on this library surface.
It does not expose disabled checks through production configuration.
Boolean and numeric getters follow the concrete vector method table: Short widens to Int/Long, Int to Long and Float to Double; Byte, DateDay, Time32 and OID extensions gain no extra Long getter.
DateMilli's Long getter divides raw milliseconds into epoch days toward zero.
An unsupported getter fails before the validity check; a supported null getter with checks enabled reports the physical leaf index.
With checks disabled it reads the stored payload, including nonzero null payloads.
`object()` always applies logical nullness and retains its result and decoding reservation in `OwnedValue`.
The caller borrows that value through `value()`.
`get_bytes` and `byte_span` borrow payload storage without checking validity; pointer spans are supported by fixed/variable-width and run-end readers, but not union/named-leg readers.
The fixed binary LongLong getter uses its source 16-byte row stride, including on null rows, and returns a bounds error outside retained bytes.
Numeric `get_as_*` and `get_decimal` require the concrete direct Numeric/Decimal class; an indirect reader retains forwarding primitive methods but does not become a NumericVector.
Decimal getters read null coefficients and reserve materialized/conversion scratch before allocating.

`vector_for` resolves Struct children and named DenseUnion legs; missing names return no reader.
A named leg masks `is_null` by its discriminator while its primitive/object getters use the stored inner offset.
Its index selection, or a range on a direct leg, translates offsets into an inner selection and drops that mask.
Those offsets may be negative or outside an empty/inactive child; selecting them succeeds until a later operation consumes the corresponding storage.
A range on an already indirect leg reader preserves the mask, matching `IndirectVector.select(start, len)`.
A first direct range retains Slice topology; another range over an indirect reader reserves and materializes translated selection indices even when its rows are contiguous.
`Selection::All` invokes the same range behavior over the complete reader.
`struct_child` also admits a named Struct leg, while `list_elements` and list offsets admit the corresponding plain or named-leg list reader.
`list_start_index` and `list_count` return signed i32 values.
Fixed lists compute start with wrapping multiplication and return the declared count without accessing row storage.
Variable lists read their stored start directly; count reads end before start and uses wrapping subtraction.
Raw list extraction separately checks the complete child range before publishing retained element views.
Run-end wrappers reject reference nested access even when their resolved physical leaf is a container.
`map_keys`/`map_values` return complete first/last Struct children or Map entry children; parent selections do not select those elements.
`CellRef::raw_struct_field` and `raw_list_elements` are separate physical layout operations that resolve indirection and retain child owners.
Raw access does not mask a child's payload with its parent's null bit and does not grant reference expression-reader method admission.

`tests/execution_cells.rs` covers primitive null payloads, unsigned interpretation, getter admission, nonnullable validity, union leaf identity, composed selections, run-end slices and end-domain admission, nested retention, DateMilli units and allocation failure release.
`tests/physical_layout.rs` adds native absent-leg containers, raw primitive failure routing, delayed inactive-offset admission, named-reader selection exceptions, canonical declarations, direct numeric/byte methods, shorter logical run lengths, malformed layout rejection and retained-owner failure cases.
`cells/descriptor.rs` covers nested checked metadata projection, retained projection charges, allocation failure release, declared and ordinal discriminator identity, wrapped named-leg reads, custom child order, empty union types, descriptor depth admission and deep Struct joins under independent finite budgets.
`cells/descriptor/metadata_tests.rs` covers independent field/type/nullability demand, typed failure ordering, delegated run-end admission, source-native fixed widths, structural reads and retained charges on failed metadata admission.
Native partial container storage and writer construction remain separate from this descriptor prerequisite; public `from_physical` retains its strict SDK-declared input validation.
These are unexecuted source regressions.
Query frames, parameters, spill transport and expression consumers still require a coordinated physical-cell rollout before end-to-end null-check compatibility can be claimed.
Container writers, physical page transport, hash/metadata factories and production consumers remain separate work.
Full object readers require tagged custom union legs, null-field omission, collection equality and registered extension decoding; `object()` remains the logical `Value` materializer and canonicalizes its timestamp zone only.


== Private scalar write and copy foundation

The crate-private `ScalarWriter` is a single-writer transient whose completed native storage is consumed into an `ExecutionVector`.
It supports Null, Boolean, fixed-width and variable-width storage, including the concrete primitive and byte methods admitted by scalar extension wrappers.
It does not publish mutable buffers or construct an unchecked Arrow array.
`ScalarReader` borrows the transient for primitive and byte reads; Rust borrowing excludes mutation while that reader is used.
The immutable reader and the transient reader share borrowed scalar storage kernels with SDK ingress.
Logical row admission remains separate from initialized byte-span admission.
A native buffer owns and charges its explicitly initialized extent, including zeroed growth from the source's minimum-128/doubling schedule.
SDK reads remain confined to their retained buffer slices.

Logical row count, byte/bit append positions and initialized extent are retained separately.
`ensure_capacity` and setters can create logical rows without advancing append positions.
Fixed setters widen their index before applying the setter stride.
Capacity requests, primitive getter strides, pointer spans, fixed copier products and variable offset reads preserve the source's wrapping i32 arithmetic.
Decimal object/coefficient reads retain Arrow Java DecimalUtility's wide index multiplication.
Every resulting span is still checked against retained initialized bytes.
`set_null` extends count where required and changes existing validity without promoting a nonnullable vector or clearing its payload.
`write_null` promotes nullability and then writes an undefined cell.
`clear` zeroes the complete retained allocations, resets count and append positions, and preserves established nullability and capacity charges.
DateMilli appends multiply epoch days with JVM wrapping; inherited Long setters and raw copies retain milliseconds.
Fixed byte writes retain their actual input length, and FixedSizeBinary LongLong methods retain their independent 16-byte stride.
A source-produced row with too few retained bytes for a particular getter remains safely representable; that getter returns a checked bounds failure.
`finish` does not truncate setter-created rows or add missing payload bytes.

`ScalarCopier` borrows one admitted scalar source view and a mutable destination.
Its outer type check and class-specific storage factory preserve their separate admission and nullability-promotion order.
The Null-source override belongs to outer dispatch; a direct storage factory still applies the destination's class or extension requirement.
It implements row, selected-row and range schedules separately.
Variable row and range preflight read the ending offset before the starting offset; selected-row preflight and payload copying read the starting offset first.
Indirect bulk copies reserve and translate their indices before mutating destination storage.
Fixed and variable copies preserve raw validity and payload, including nonzero payload under null bits.
Variable row copying appends validity ones for nonnullable sources and selected validity bits for nullable sources, retaining their distinct byte cursors.
Boolean copying uses the source null guard and writes a cleared null payload.
A Null source writes destination nulls without reading a source payload.
Variable ranges with nonpositive length return without touching buffers after factory admission; indirect ranges retain their selection translation contract.
This is an internal scalar kernel, not a universal recursive copier or a resource-only transport format.

`WriteError::Reference` retains unsupported-method, invalid-copy-source, concrete class-check, extension-requirement and determinate reference bounds failures without choosing a host exception adapter.
`CheckFailed` and `RequireFailed` preserve Kotlin's distinct IllegalStateException and IllegalArgumentException producers; neither matches the promotion-caught `InvalidCopySource`.
Those failures preserve completed mutations and leave the writer usable for a subsequent operation or promotion.
A native budget, arithmetic or retained-storage admission failure before mutation also leaves the writer usable.
A native admission failure after mutation marks the private writer `NativeAborted`; further writes and publication fail until `clear` resets it.
Safe borrowed reads remain possible, and dropping either state releases every retained lease.
There is no rollback or unconditional failure latch for reference semantic errors.
The existing raw absent-primitive read failure still requires an explicit Kotlin or Clojure adapter at a future production boundary.

`cells/write/tests.rs` records scalar method admission, signed setter behavior, mutation prefixes, recovery, copying, initialized spans, SDK/native reads, malformed UTF-8, exact floating/decimal bits, DateMilli units and reservation retention.
The source has not been compiled or executed under the Phase 1 gate.
No production expression/query/format consumer or process null-check setting is switched by this foundation.
Full-object writers/readers, container promotion, relation writers, physical transport and production adoption remain required follow-on work.
