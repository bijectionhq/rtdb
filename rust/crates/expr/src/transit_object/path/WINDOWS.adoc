= Stored Transit Windows Path

The registered Transit reader parses a Java URI before invoking the filesystem provider.
A value with no URI scheme becomes a default file path.
A hierarchical file URI decodes its path and maps a server authority into a UNC root.
IPv6 hosts use the Windows literal spelling, including the zone separator.
Drive, UNC, directory-relative, drive-relative and relative roots keep their source distinctions.
The normalized path preserves dot components and collapses repeated separators outside its root.
An extended path prefix requires the corresponding absolute or UNC root.

The Windows path object keeps normalized text and the root boundary needed for iteration.
Equality and hashing apply Java's simple uppercase mapping to each UTF-16 unit.
The original casing remains in the serialized string.
Supplementary characters retain their individual UTF-16 units during comparison.
URI parsing, normalized allocation and Transit output remain within the expression caller's allocation scope.
