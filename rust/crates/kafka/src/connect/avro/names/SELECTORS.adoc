= Java names

link:../names.rs[The internal helpers] provide a call-local Java name policy and borrowed canonical name parts.
The policy neither registers nor reads a process-global validator.

Name validation uses the pinned link:README.adoc[UTF16 category data and source proof].
Apache Avro 1.11.4 Schema.Name splits at the final dot, validates only the suffix, and uses the prefix in preference to a supplied namespace.
Empty namespace suppresses inheritance; namespace text is otherwise preserved.
The native scoped policy returns an explicit empty namespace for global names so subsequent qualification retains that identity.
Borrowed name parts expose checked owned-text and fullname payload lengths; container headers, repeated namespace copies, and other conversion allocations remain the caller's admission responsibility.
This policy alone does not impose Java's ordered canonical-reference grammar or primitive declaration-name restrictions.
