= Exact typed Connect text

This registered schema-object capability preserves every Java UTF16 unit in field names, schema names/docs, parameter keys/values and admitted String-class values.
The production graph and default path still needs to adopt this capability.
The existing programmatic JavaValue::String(String) representation and the admitted JavaValue::StringUnits(Text) representation describe the same java.lang.String class.
Java object identity remains a separate observation.

== Values, operators and owners

Text is the existing passive immutable owner of shared JavaString storage and its captured reservation.
JavaValue::string copies a borrowed JavaText after admission; string_text borrows either String representation without encoding or allocation.
String equality compares exact units, hash computes the wrapping 31-fold over those units, and Comparable subtracts the first differing unsigned UTF16 units or the signed32 unit counts.
Logical-name recognition likewise compares the complete exact name against the recognized ASCII name.

Field and Metadata remain passive values inside the immutable SchemaObjects owner produced by the passive single-writer SchemaObjectsBuilder transient.
The existing &str setters delegate to borrowed JavaText setters.
Duplicate field detection compares units before text admission or copying.
The builder retains its existing source-stage contract; the eventual graph caller must still preserve actual SchemaBuilder checkCanSet and metadata assignment timing.

SchemaHandle retention first retains each arena's existing structural charges, then visits its actual name/doc text, parameter key/value text, field-name text and default value owners in object order.
Imported families preserve those original owners and their existing reservations.
Typed default, List, Map and PreviousValue traversal reaches independently admitted text in the same nested-owner walk as binary/map storage.
JavaMap::retain covers map storage and key control storage.
`retain_contents` additionally visits the actual entry values and key values.
The creating schema family remains a separate caller obligation whenever a value can contain Struct IDs.

link:ADMISSION.adoc[The arena admission contract] specifies the checked text temporary/storage and Text-containing slot bounds.
Copies admit their temporary unit buffer and final shared backing separately because both coexist during construction.
Only the backing's lease is captured by Text; the temporary reservation remains in the current conversion context.
Fresh contexts retain the captured existing reservation rather than reserving that heap again.
