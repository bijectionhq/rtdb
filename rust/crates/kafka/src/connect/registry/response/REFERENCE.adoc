= Registry REST response beans

The ordered-byte decoder constructs nullable REST bean owners.
The Avro writer schema-ID lookup uses the borrowed-byte `SchemaString` entry point for the common UTF8 envelope below.
The published decoder and observed-window regression sources await execution in Phase 2.
HTTP stream segmentation, persistent Jackson symbol-table state and effective shipped Jackson selection remain required for wider typed HTTP use.
The Phase 2, whole-native memory and source-completeness gates remain open.

== Source profiles

Confluent7.8.0 JacksonMapper constructs a fresh JsonMapper with ALLOW_NON_NUMERIC_NUMBERS enabled.
The declared Confluent profile uses Jackson databind/core/annotations2.16.0.
Connect JSON4.4.0 declares databind2.21.7, whose matching BOM selects core2.21.7 and annotations2.21.
These declarations do not establish the effective runtime classloader or shaded distribution.
The retained link:DEFAULT-PROFILE.adoc[worker classpath evidence] establishes Jackson core/databind 2.21.7 for the pinned C84 reference workers; packaged distributions retain their separate qualification.
Profile is explicit at each decoder entry point.

Both inspected profiles preserve duplicate field order, nullable primitive wrappers, Java String UTF16 units, scalar coercions and ordinal enums.
The newer profile rejects zero-prefixed quoted enum ordinals such as "01" and applies the number-length limit to coerced Integer strings.
Core2.21.7 rejects raw three-byte UTF8 surrogate encodings when decoding text; its lazy string skip still checks only continuation bytes.
Escaped isolated surrogate value strings are retained in both profiles.
Core2.21.7 requires escaped field-name surrogate pairs, while2.16.0 permits isolated escaped units.
The exact UTF8 value-string decoder uses bitwise OR to emit the high UTF16 unit of a four-byte encoding, while field-name decoding uses addition.
These differ for accepted overlong four-byte encodings below0x10000: raw F0 80 80 80 produces FFC0 DC00 in a value and D7C0 DC00 in a name.
Lazy skip validates continuation bytes without publishing either decoded value.
Core2.16.0's literal-suffix error decoder rereads the non-ASCII lead byte;2.21.7 advances and rewinds that byte and checks the decoded code point truncated to a Java char.
The bounded-byte fixtures retain these different observations.

== Avro writer schema-ID response

Confluent 7.8.0 `RestService.getId` reads the HTTP 200 response as `SchemaString` (RestService.java:319–324, 986–1005).
Its setters preserve the schema string and explicit nullable fields (SchemaString.java:35–115).
`CachedSchemaRegistryClient.getSchemaByIdFromRegistry` then constructs a `Schema` from that response and invokes the provider (CachedSchemaRegistryClient.java:331–350).
`Schema` defaults a null type to AVRO and null references to an empty list (Schema.java:140–150).

The native lookup runs the decoder after the existing bounded HTTP collector completes.
Confluent begins reading the stream within `readValue` after HTTP 200 and has separate absent-body and error-body branches (RestService.java:319–345).
The common UTF8 envelope admits one literal `schema` field containing a string, an optional literal `schemaType` field containing null or AVRO, and an optional literal `references` field containing null or an empty array.
It requires unique names, a complete object and valid UTF8 without a BOM or Unicode escapes.
The bounded object uses the same string, null and empty array values in both inspected source profiles.
The three member names and strings fit within both profiles' limits under the 256 KiB response cap.
The production borrowed decoder uses Jackson221, the default parser profile identified by the link:DEFAULT-PROFILE.adoc[pinned Gradle worker classpath].
An allocation-free scan selects the subset before decoding, and the typed projection reserves its native UTF8 strings before copying them.
The existing native subject request omits absent or null type and preserves explicit AVRO.

Additional fields, other shapes and unsupported projections use the existing generic JSON path on the same collected response.
A native allocation refusal in the typed path propagates.
The typed lookup performs no provider parse and retains no parser or symbol-table state.

== Bean construction

SchemaString has a default constructor and encounter-ordered setters; its public String constructor is also an implicitly discovered scalar creator.
Its initial schemaType is AVRO and references is empty, while explicit setter nulls remain null.
Schema has nine creator properties, including lowercase ruleset, and separately exposes the ordinary ruleSet setter.
Creator duplicates replace the pending argument, and each argument contributes to the completion count once.
When all arguments have appeared, Jackson advances to the following field or object end before constructing the bean.
Ordinary pre-creator setters are buffered by prepending and replay in reverse encounter order.
After construction, lowercase ruleset has no fallback setter; that failure precedes decoding a lazy string value.

SchemaReference, Metadata, RuleSet, Rule, SchemaTags and SchemaEntity are fully decoded even when the immediate native caller would ignore their fields.
Metadata normalizes tags, properties and sensitive in that constructor order.
Rule supplies null kind/mode defaults and normalizes tags/params without invoking Rule.validate.
Sorted constructors reject null set members and null tag-map values at construction.
Creator Map/Set values assigned through Metadata/Rule's final SortedMap/SortedSet fallback fields fail reflective class assignment after their complete value has decoded.
Explicit post-creator nulls can remain in those fields.
RuleSet creator null lists become empty; later null assignments remain null and null list members remain present.
SchemaEntity computes normalizedPath at construction; later reflected entityPath changes retain that earlier normalized value.

== Owners and admission

The Registry transport returns a passive RawResponse whose RawBody retains the admitted byte vector through decoding or final release.
The existing generic response path parses these borrowed bytes through the admitted JSON materializer.
The production cursor borrows the response slice.
In fixture builds, Cursor is a passive call-local choice between the borrowed slice cursor and the observed-window lexical transient.
SliceCursor and Input retain the published borrowed-byte rules; SliceName retains an Input snapshot.
The observed branch owns one existing parser window, admitted field-name values and a bounded inline numeric spelling.
Name is a complete slice-name or admitted JavaString value, so repeated name comparisons and retained map keys never repeat an observed source read.
Token, Frame, Profile, Utf8Demand and the failure variants are passive value tags.
TextBufferObservation is a passive caller-owned observation of the actual source text-segment capacity in UTF16 units at a demanded value's opening-quote byte offset.
Cursor borrows those observations with the response bytes; it retains no observation allocation or authority callback.
TextBufferDemand is a passive scan-local output-segment counter and allocates no source segment storage.
Creator is a single-writer transient seen-mask with an explicit constructed state.
The separate Schema setter buffer is an admitted Values owner and is consumed in reverse order.
SchemaString, Schema, Reference, Metadata, RuleSet, Rule, SchemaTags and SchemaEntity are passive typed result values.
StringSet, Properties and Tags retain collection class/ordering state used by constructor and fallback-field behavior.
No owner starts a task or retains the admission callback.

Values checks array layout, multiplication and allocator margin before context.reserve and try_reserve_exact.
Growing a vector reserves the replacement while the old vector and its charge remain live, then moves values and releases the old buffer.
Payload fields precede their reservation fields, so retained payloads are destroyed before their own leases.
JavaString::copy_utf16_with_admission reserves its checked shared backing before copying units, and retains the returned lease.
Decoded-string scratch and output overlap is separately admitted.
The existing ConversionContext retains every accepted charge until context drop; this conservative lifetime also covers buffers released earlier.
Returned strings and collections retain their own reservations and can safely outlive the context.
Native admission/allocation/overflow anomalies remain outer Failure::Native values.
The cursor allocates no generic serde_json::Value tree and gives the private RawValue field name ordinary unknown-property treatment.

== Parser boundary still requiring integration

The plain schema/schema_string entry points have no source text-buffer capacity observation.
For demanded strings of at most20million UTF16 units, that capacity does not affect the length guard.
Crossing that bound without a qualified observation returns an outer unsupported-source-profile anomaly, not a claimed Jackson length failure.
The qualified schema_with_text_buffers/schema_string_with_text_buffers entry points borrow TextBufferObservation values for demanded UTF8 strings.
Each supplied capacity must be the actual positive current Java TextBuffer segment capacity at that byte offset, bounded by the Java array range.
The caller must account for earlier numeric tokens, name decoding, demanded strings and recycler reuse when deriving that observation.
A fresh default recycler starts at200 units, but reusing200 for every string is not a valid general observation.
Each offset must have at most one observation; unneeded observations do not cause a parser demand.
Matching observations are ignored for reader encodings because their shared text and reader-window branches remain outside this capability.
Over-limit reader strings therefore remain unsupported.
The observations are borrowed and any retained caller-owned storage remains the caller's admission responsibility.

For a qualified UTF8 demand, string length is checked at completed output segments and at final contents demand, as in TextBuffer and UTF8StreamJsonParser.
Replacement segments grow by50percent with a500-unit minimum and65,536-unit maximum.
Malformed escape and UTF8 decoding can fail after20million units but before the next completed-segment check.
At the next raw-character demand with a full output segment, source input exhaustion is demanded before segment validation.
A supplementary decoded pair can also validate the segment between its two emitted units before another raw-character demand.
The qualified source fixtures preserve those demand points and distinguish an unavailable observation from a Java failure.
The current production transport's256KiB response cap is below the over-limit string witnesses; the direct decoder's borrowed byte input has no such cap.

RestService320–323 passes HttpURLConnection.getInputStream directly to ObjectMapper.readValue.
UTF32Reader and ReaderBasedJsonParser decode ahead in source-dependent input windows.
An invalid UTF32 suffix can fail before a completed root bean is returned, and a supplementary character at an output-buffer boundary uses UTF32Reader's retained pending-char branch.
Core2.21.7 also reports a non-identifier UTF8 literal suffix when decoding that suffix reloads its input buffer.
The legacy byte-only cursor has no HTTP read-segmentation observation and does not reproduce those reader-window effects.
The inactive link:window/REFERENCE.adoc[observed-window entry points] consume the published UTF8/UTF16/UTF32 windows directly for the qualified lexical branches.
The link:window/utf8/REFERENCE.adoc[UTF8 symbol cursor] composes actual ByteQuads lookup before missed-name decoding without accepted-name observations.
The observation-driven diagnostic entry points retain a borrowed successful canonicalizer-result observation at each field occurrence and explicitly reject unmodeled error-token, rewind and over-limit Reader branches.
Actual HTTP observation capture and persistent mapper symbol state remain required for that entry point.

JsonFactory also shares seeded ByteQuadsCanonicalizer/CharsToNameCanonicalizer state across parser calls and enables FAIL_ON_SYMBOL_HASH_OVERFLOW by default.
The borrowed cursor preserves decoded names and member order but carries no persistent mapper symbol state.
Adversarial symbol-hash overflow, mapper reuse and their failure order therefore remain required.
The local cursor's name-length/decode-buffer checks do not discharge that obligation.

Typed HTTP projection must preserve a nullable Java UTF16 schema text, subject and reference name until their actual consumer demands them.
The native schema and reference strings require a coordinated carrier change for wider typed HTTP use.
No null-to-empty or isolated-surrogate-to-replacement projection is authorized here.
Version lookup scheduling and caching remain owned by the separate Registry timing plan.
