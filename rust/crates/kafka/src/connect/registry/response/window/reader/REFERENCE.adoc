= Registry Reader-symbol decoding

`schema_string_from_reader` and `schema_from_reader` compose the existing ordered bean decoder with the persistent character canonicalizer.
They consume a fresh detected `ReaderInput`, the observed positive parser character-buffer capacity, one actual factory's `ReaderSymbols` root, and a borrowed `InternAuthority` in the caller's ConversionContext.
ReaderInput contains an owned UTF16 or UTF32 decoder before any decoder read, read_one or ready call or parser character-window allocation.
Bootstrap lookahead and BOM removal have already occurred.
UTF8 byte parsing is excluded by this input type.
The registered capability remains under the response module's test gate; the installed HTTP/JSON route is unchanged.

== Construction and field demand

Construction snapshots the root's child before allocating the parser character window, matching ByteSourceJsonBootstrapper.constructParser's constructReader, rootCharSymbols.makeChild and ReaderBasedJsonParser constructor argument order.
The child, lookups and release use the same ConversionContext.
The lexical profile comes from that child's immutable factory observation.
A conflicting retained UTF32 profile is rejected before the first parser character, followed by the normal constructed-parser close stage.
A preparation failure drops the native decoder and any prepared child without inventing a parser close observation.
ObjectMapper constructs the parser before entering _readMapAndClose's try-with-resources; RestService explicitly closes its input only after readValue succeeds and separately disconnects its HTTP connection in finally.
Actual HTTP disconnect and read/recycler observations remain outside this entry point.

The passive NameAuthority transient owns either the legacy successful-name observations, an actual child plus a call-borrowed interning authority, or its closed state.
The Reader branch accumulates the demanded exact UTF16 name in admitted scratch and calls ChildSymbols.find before colon validation and value prefetch.
Hits reuse the admitted symbol's JavaString backing.
Misses demand the supplied interning authority at the canonicalizer's existing source stage.
This branch receives no NameObservation and does not assume successful canonicalization.
Bean constructors, nullable values, duplicate-field order and lexical demand continue through the existing cursor and bean machines.

== Close and failure ownership

Constructed-parser close first closes the underlying Reader, then releases the symbol child in ParserBase.close's finally stage, then releases the parser character buffer when symbol release succeeds.
Symbol release still runs after an input close failure.
A symbol-release failure replaces an earlier input close failure, matching ordinary Java finally precedence.
A pre-existing decode failure remains primary and retains that resulting close failure in ObservedDecode.suppressed_close.
On successful decoding, any close failure prevents publication of the returned bean.
The closed transient does not close or release symbols twice.
Any retained native character buffer drops with the cursor if the source release sequence failed before releasing it.

Accepted symbols can publish after a lexical, bean or source I/O failure.
The symbol child's own native failure poison suppresses its partial publication.
Native admission and interning errors propagate unchanged.
Source name-length and collision failures map to FailureKind::Constraint; the canonicalizer's retained rehash-count inconsistency maps to FailureKind::Unchecked.
The existing typed failure vocabulary does not establish complete Java exception text or location rendering.

ReaderInput, NameAuthority, cursor and decoder are passive call-owned transients.
The persistent root remains the existing passive immutable-snapshot identity.
No task, retained callback, additional budget pool or background lifetime is added.
Existing owner methods admit scratch, replacement arrays and immutable text before allocation, retaining old/new overlap through the same context.
The root, symbol names and returned bean text keep their original reservations after the context ends.
Borrowed source tapes and interning authority must outlive the call; the authority is never retained after it returns.
