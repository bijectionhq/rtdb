= Java metadata string decoding

`JavaText` borrows a Kafka string payload and exposes the OpenJDK 25 UTF8 replacement decoder used by Kafka's `Readable.readString`.

* Decoded identity uses Java UTF16 code units.
** Malformed groups produce one U+FFFD according to `String.decodeUTF8_UTF16` and its `malformed3`/`malformed4` helpers.
** A complete UTF8 surrogate encoding produces one replacement character.
** Equality, ordering and the wrapping 31-based string hash operate on the decoded units.
** Supplementary scalars contribute two UTF16 units.

* Output storage belongs to the caller.
** Iteration, hashing, comparison and exact length measurement allocate no output storage.
** The caller admits the measured UTF8 length before supplying an output slice to `write_utf8`.
** An undersized destination remains unchanged; a larger destination retains its unused suffix.
** Kafka's string limit applies to the original wire payload before replacement expansion.

* The source fixtures cover replacement boundaries and decoded identity.
** Four regressions cover valid scalar boundaries, malformed prefixes and surrogate groups, all single bytes, iterator clones, exact size and unchanged short outputs, UTF16 ordering, and signed hash wraparound.
** The integration test file imports the production decoder directly without adding a producer module declaration.
** Runtime verification remains a Phase 2 obligation.

`sources.json` pins the Kafka source archive, the OpenJDK source archive and every consulted member.
`COPYRIGHT` retains each source's complete leading notice.
The accompanying license and notice files are copied verbatim.

This decoder is a prerequisite for the retained metadata snapshot and explicit RoundRobin selection.
The whole-producer construction and background allocation bound remains open.
