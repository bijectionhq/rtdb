= Native plan representation

The canonical expression, relation and statement types define the native plan representation.
Their current public serialization traits remain part of that API while exact-text tree ownership and format-specific replacements are implemented.

== Private JSON prerequisite

The private JSON module retains exact string units, emits the existing valid-UTF8 JSON spelling and escapes isolated units as JSON string escapes.
Its borrowed recipe encoder preserves raw form variants, physical value variants, ordered entries and the five replacement fields without evaluating metadata.
A shared iterative traversal handles recursive raw forms and physical values under admitted call-local storage.
Counting and filling share the encoder and retain the admitted traversal capacity; output scratch remains charged while the completed document acquires an independent lease.
The private regression sources preserve existing JSON schemas, unit distinctions, failure prefixes and allocation lifetimes.
Public tree serialization, canonical node ownership, semantic consumers and production literal binding require their dependent migrations before exact-unit tree input is exposed.

== Borrowed raw-form views

The internal cross-crate view API borrows the existing canonical raw forms and physical literal values without copying their text, children or map keys.
Child views and iterator items retain the original source lifetime, including when their intermediate parent view or iterator has been dropped.
Indexed raw sequences use child positions; `get` returns an optional child, while `at` and half-open `slice` use Rust's indexing panic contract.
Iterators preserve source order, support both ends, report exact remaining lengths and remain exhausted after their final item.
Metadata admission, SQL metadata classification, host compilation, explain rendering and private JSON encoding consume these views.
Physical literal strings and keyword names have separate borrowed UTF8 cases, and five recursive literal container cases expose borrowed children.
The sealed physical leaf view admits the other 34 variants; the private JSON adapter retains its existing 35-variant guard and serializer, including its independent UTF8 support.
The recipe encoder writes borrowed UTF8 through the existing JSON string kernel and passes proved physical leaves through that unchanged guard.
The owned enums, their generic serialization traits and their programmatic constructors retain their existing contracts.
The views add no text or node owner, retained lease, exact-unit producer or alternate representation.
