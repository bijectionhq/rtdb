= Certificate identifiers

`CertificateIdentifiers` is a passive immutable value decoded from an already parsed X.509 certificate's encoding.
It owns an independent memory reservation covering parsing scratch and retained identifier bytes.
It validates certificate identifier framing, not certificate signatures, validity, other extension contents or trust.
The shared value is intended for Java PKCS12 issuer-chain recovery and transport-owned PKIX path selection.

The source contract is Eclipse Temurin 25.0.1+8 `CertificateExtensions`, `X509CertImpl.getExtensionValue`, `SubjectKeyIdentifierExtension`, `AuthorityKeyIdentifierExtension`, `KeyIdentifier`, `SerialNumber`, and the `GeneralNames` implementations in `lib/src.zip`.
SKID access preserves the original inner extension encoding, including accepted BER forms.
AKI access returns a canonical DER OCTET STRING only after every AKI field parses successfully.
Serial numbers preserve arbitrary signed Java `BigInteger` values as minimal two's-complement bytes.
Malformed noncritical AKI is absent; malformed noncritical SKID remains available through Java's last-unparseable-extension fallback.
A successfully parsed SKID takes precedence over malformed copies regardless of input order.
Two successfully parsed copies of either identifier fail, while an unparseable noncritical copy does not displace a parsed copy.
Malformed critical identifier extensions fail.

General-name validation follows the constructor selected by `GeneralName`, including the permissive DER DNS constructor, opaque X400 values, EDI primitive context tags, and registered `OIDMap` extension classes that fail `OtherName`'s interface cast.
URI syntax uses the shared Java `UriParts` parser.
Numeric IPv6 scopes are supported through the signed 32-bit scope limit, and IPv4-mapped addresses with any scope are invalid.
Named IPv6 scopes, decimal scopes exceeding that limit, and trailing-dot URI hosts that reach Java's `InetAddress` fallback currently return `rtdb.tls/unsupported-identifier`.
These environmental resolution cases remain explicit errors even inside noncritical AKI; they are not classified as malformed extensions.
A passive local-interface and host-resolution adapter remains required for those cases.

The ASN.1 reader follows pinned `DerValue`, `DerInputStream`, and `DerIndefLenConverter`, including opaque definite bodies and zero padding produced when scanned length headers shrink.
Constructed OCTET STRING processing is iterative, with temporary ownership bounded by input size.
Admission failures propagate without becoming identifier absence, and the reservation releases when decoding fails or the result drops.
The regression sources cover signed serials, canonical versus original encodings, all general-name choices, malformed and duplicate extensions, BER forms, deep constructed octets, environmental URI errors, and allocation release.
No identifier regression has been compiled or executed during Phase 1.

`CertificateAlternativeNames` is a separate passive immutable view of a parsed subject-alternative-name extension.

* Its original inner extension bytes implement `SunCertPathBuilder.altNamesEqual`, which compares `SubjectAlternativeNameExtension.getExtensionValue()` with `Arrays.equals`.
Case, name order and accepted BER encodings remain significant even when the parsed names denote the same values.
* Malformed noncritical SAN is absent.
* A parsed copy survives unparseable copies.
* Two parsed copies or a malformed critical copy fail.
* The view reuses the same `GeneralNames` parser and environmental URI errors as certificate identifiers.
* The certificate-framing scanner is shared with `CertificateIdentifiers`.
* It owns its parsing reservation independently until the view drops.

SAN regression sources cover original-byte equality, empty and malformed names, duplicate handling, BER retention, environmental URI errors and reservation lifetime.

`CertificateBasicConstraints` and `CertificateKeyUsage` expose passive immutable Java CA-selection results.
Each view owns its parsing reservation independently until it drops.

* BasicConstraints follows `BasicConstraintsExtension` and `X509CertImpl.getBasicConstraints`.
Absent extensions, empty sequences and non-BOOLEAN first fields yield `-1`.
A nonzero CA flag without a path length yields `i32::MAX`.
Explicit signed path lengths retain negative values and accept redundant BER sign bytes within Java's integer range.
Fields after a parsed path length are ignored.
* KeyUsage follows `KeyUsageExtension` and `KeyChecker.verifyCAKeyUsage`.
Absent usage permits certificate signing.
Parsed usage requires bit five; short arrays supply false for missing bits.
The parser accepts one primitive OCTET STRING wrapper and ignores nonzero BER padding bits beyond the declared bit length.
* Malformed noncritical extensions are absent.
* A parsed copy survives unparseable copies.
* Malformed critical extensions and duplicate parsed copies fail.

Thirteen CA-extension regression sources cover Java defaults, signed integer limits, ignored fields, bit boundaries, framing, duplicate handling and reservation lifetime.
