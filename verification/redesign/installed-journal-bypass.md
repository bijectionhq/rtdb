# Installed-journal bypass audit

## Decision and scope

D05 assigns the portable guarantees to deployments with an installed Logkeeper journal.
Directory deployments and standalone legacy journals retain their existing semantics.
Cutover uses a fresh deployment UUID and the installed manifest.
Portable checkpoint publication requires an exact catalog digest and the journal's chosen checkpoint.
A directory root, including a legacy root without a digest, supplies neither decision. [Installation and custody](../../dev/doc/rtdb-multi-installed-journal.md)

The audit follows the [W7 effect-path format](../PROGRAMME.md#w7--effect-path-and-bypass-audit) and includes retries, stale routes, member lease loss and partial provisioning.
Here, an installed deployment means the exact canonical deployment UUID in the authenticated placement, together with its serving and checkpoint media.
In a mixed cell, the directory that owns access to those media reserves that UUID before provisioning.
All directory processes with access to the cell's keys and media use that same directory.
The reservation occupies the UUID even if a caller supplies a different name for it.
Configured installed names select the journal on their workers and gateways.
An ordinary directory name still resolves to its own directory record and UUID.

## Evidence and open obligations

This is a production source audit.
It provides no model result or provider qualification.
Direct write access to raw directory tables, object media or key vaults is outside the RTDB call paths above.
Installations previously sharing a directory must establish the reservation on their existing canonical UUID before relying on this boundary.
A conflict with a directory record is a provisioning error and requires a fresh deployment identity.

The unmutated baseline ran on RTDB revision `7cd65e3695` and the controls ran on `443f539212`.
The Directory baseline passed 46 tests with the `network` and `dynamodb` features enabled and an in-memory DynamoDB Local 3.3.2 endpoint.
It exercised the shared contract against Memory, TCP and DynamoDB and checked that the local reservation survives a restart.
The hosted-retirement and installed writer-replacement baselines also passed.
The writer-replacement fixture exercised the mixed cell's legacy deployment, the installed PGWire and Flight paths, eight refused directory controls, and the installed holding and grant after pressure reconciliation.

Each probe enabled a single mutation in its process.
The source changes used to build the probe binaries were restored.
The remaining effect rows are source inspection.
Background compactor assignment, fragment rejection, stage and recovery, and reaper retries still need native probes before they can carry an end-to-end verification claim.
