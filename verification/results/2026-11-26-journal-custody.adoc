= RTDB kernel study results, 2026-11-26: journal custody

== Logkeeper decommission and copy release

A logkeeper leaves a Multi cell by drain, journal balance, copy release (`rust/crates/multi/src/admin/release.rs`) and decommission (`rust/crates/multi/src/admin/decommission.rs`).
The directory fences every deployment write that newly names a logkeeper on its eligibility epoch (`rust/crates/directory/src/journal_fence.rs`), so a placement planned before a decommission certificate cannot land after it.
